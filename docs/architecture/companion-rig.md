# 헤이즐 리그

- `assets/companion/rig/` — 레이어와 소스
- `tools/split_hazel_parts.py` — 소스에서 파츠를 뽑는 빌드 스크립트
- `scripts/companion/rig_test.gd` — 리그 조립과 애니메이션
- `scenes/CompanionRigTest.tscn` — 확인용 임시 씬

## 역할

- 부위별로 나뉜 그림을 하나의 캐릭터로 묶어 움직인다
- 목표 수준은 Live2D 치비 모델(EmoteLab)의 부드러움이다
- 현재는 스프라이트 통회전이다. 메시 변형(`Polygon2D` + `Skeleton2D`)으로 옮겨간다

## 작업 흐름

1. 생성형 AI로 **전신 정면 포즈 한 장**을 만든다
2. 레이어 분리 도구(anysplit 등)에 넣어 파츠로 쪼갠다
3. 레이어별 PNG를 `assets/companion/rig/`에 넣는다
4. 코드가 조립한다

⚠️ 파츠를 **따로따로 생성하지 않는다.** 생성형 AI는 좌표 기억이 없어 매번 다른 캔버스를 낸다. 한 장에서 쪼개면 모든 레이어가 같은 캔버스에 있으므로 정합이 공짜다.

### 임시 파츠 단계

- 최종 그림이 정해지기 전에는 **도형 파츠**로 같은 레이어 구성을 채운다
- 리그 코드와 행동을 먼저 완성하고 그림이 오면 PNG만 교체한다
- 임시 파츠는 한눈에 임시로 보여야 한다. 완성도가 어중간하면 최종으로 오해받는다
- 2026-09-21 목업에서 대기·책읽기·걷기·점프·도토리 묻기·떨어지기·들어올리기가 도형으로 읽히는 것을 확인했다

## 계약

### 파일 규격

- 모든 레이어는 **원본과 같은 크기 캔버스**로 내보낸다
- 레이어에서 그 파츠가 놓인 자리가 곧 붙는 자리다. 코드가 위치를 옮기지 않는다
- 파일 하나에 파츠 하나만 담고 나머지는 투명이다
- 파일명 앞 번호가 그리는 순서다. 번호가 작을수록 뒤에 깔린다

### 떼어낼 레이어

| 파일 | 내용 | 가려진 부분 |
|---|---|---|
| `10_tail.png` | 꼬리 | 몸에 가린 밑동. **면적이 커서 여기가 제일 위험하다** |
| `20_ear_l.png` / `21_ear_r.png` | 귀 | 머리에 가린 밑동 |
| `30_body.png` | 몸통·다리·발 | 망토·가방·팔에 가린 부분 |
| `31_arm_l.png` / `32_arm_r.png` | 팔·손 | 망토에 가린 부분 |

| `41_bag.png` | 가방 | 없음 |
| `50_head.png` | 머리·얼굴 **털만** | 눈·코·입이 있던 자리 |

- `62_iris`가 분리돼야 시선이 움직인다
- 팔은 망토에 거의 가려 있어 분리 가치가 낮다. 결과를 보고 뺄 수 있다

### 회전축

코드가 파츠를 돌릴 때 쓰는 지점이다.

| 파츠 | 회전축 |
|---|---|
| 귀 | (±20, -126) |
| 꼬리 | (16, -32) |
| 팔 | (±26, -60) |
| 머리 | (0, -76) |
| 목덜미 | (0, -128) |

- 좌표계 원점은 **발바닥 중앙**이고 위가 음수다. 키는 약 160이다
- `rig_test.gd`의 좌표(원본 스프라이트 좌상단 원점)와는 다른 계다
- 이 표는 픽셀값이 아니라 **비율 계약**이다. 그림을 교체해도 유지되게 그린다
- 목덜미는 들어올려졌을 때 몸이 매달리는 지점이다
- 축이 움직이면 모든 행동을 다시 잡아야 한다

### 떼어낼 수 없어 따로 만드는 것

- **윗눈꺼풀 / 아랫눈꺼풀** — 눈을 뜬 그림에는 존재하지 않는다
- 눈꺼풀은 `50_head`의 얼굴 털에서 떠내어 코드로 만든다
- 눈꺼풀이 분리되면 내려오는 양을 0~100%로 연속 제어할 수 있다
- 텍스처 교체는 깜빡임이 3프레임이라 끊긴다. 눈꺼풀 변형은 안 끊긴다

## 주의

### 가려진 부분을 채우는 품질이 이 방향의 전제다

- 분리 도구는 파츠를 떼어낸 뒤 빈 자리를 채운다고 한다
- anysplit은 **분석적** 방식이다. 원본 붓터치를 보존하지만 없는 정보를 만들지는 못한다
- 가려진 면적이 작으면(귀 밑동, 눈 뒤 얼굴) 분석적 채우기로 충분하다
- **꼬리는 면적이 커서 평평하게 나올 수 있다.** 그때는 꼬리만 따로 그려 받는다

### 파츠를 합성 이미지에서 손으로 오려내지 않는다

- 2026-09-15까지의 파츠는 정면 포즈 한 장에서 잘라 만든 것이다
- 잘라낸 자리마다 경계가 생겼다 — 꼬리 끊김, 귀 밑동 계단, 턱의 어색한 선
- 눈두덩을 도는 띠는 눈 주변만 타원으로 오려 붙인 경계였다

### 그림자를 두 곳에 그리면 두 겹이 된다

- 얼굴에 눈구멍 음영이 있고 눈 조각에도 눈꺼풀 음영이 있으면 겹친다
- 눈을 감았을 때 밝은 타원이 드러났던 원인이 이것이다
- 음영은 그 음영을 만드는 파츠 하나만 갖는다

### 배율 기준을 그림 하나에 묶지 않는다

- 눈 크기를 얼굴 폭에서 유도했더니 얼굴을 다른 크롭으로 교체했을 때 깨졌다
- 레이어가 전부 같은 캔버스에서 나오면 배율 유도 자체가 필요 없다

### 팔이 짧아 손이 머리 위로 못 간다

- 어깨에서 손까지 24, 머리 반지름 34인 치비 비율이다
- 두 손으로 무언가에 매달리는 포즈가 물리적으로 안 나온다
- 창 모서리 매달리기는 한 손과 한 발로 잡는 비대칭 포즈로 우회했다
- 파츠를 더 쪼개도 안 풀린다. 제대로 된 매달리기는 **메시 변형 리그로 옮긴 뒤**로 미룬다

### 페르소나 제약

- 성별 기호(속눈썹 강조·리본·체형 강조)를 넣지 않는다 — `companion-persona.md` §1
- 데포르메 비율은 이 제약과 무관하다. 금지 대상은 생애 단계 신호다
