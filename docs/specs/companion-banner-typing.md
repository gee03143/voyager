# 컴패니언 배너 발화 연출

헤이즐의 말이 배너에 나타나는 방식. 문장 교체, 타이핑, 발화 효과음, 그에 딸린 선택지·도장의 타이밍을 정한다.

## 동작

### 문장 교체
- 배너에 새 문장이 뜰 때 이전 내용이 먼저 흐려져 사라진다
- 이전 내용이 사라진 뒤에 새 문장이 한 글자씩 찍힌다
- 퇴장 페이드는 300ms
- 문구 줄과 보조 줄은 함께 흐려진다
- 두 줄의 교체 시점은 같다
- 보조 줄은 타이핑하지 않는다. 사용자가 쓴 제목이나 세션 시각 표기이지 헤이즐의 문장이 아니다
- 문장이 찍히는 동안 줄바꿈과 말풍선 높이는 변하지 않는다

### 타이핑 속도
- 글자당 25ms
- 문장 전체가 0.8초를 넘으면 그 안에 맞춰 빨라진다
- 상한은 영어 문장을 위한 것이다. 한국어는 30자 규격이라 대개 비례 구간에 머문다

### 타이핑을 돌리는 조건
- 문구 줄과 보조 줄을 합친 내용이 직전과 다를 때만 타이핑한다
- 문구 줄은 번역과 포맷이 끝난 최종 문자열로 비교한다
- 둘 다 같으면 완성된 화면을 그대로 유지한다
- 인자가 없는 문장은 연달아 나올 때 글자까지 같으므로, 문구 줄만 보면 새 반응인데도 아무 일도 일어나지 않는다
- 앱을 열 때 뜨는 첫 문구도 타이핑한다

### 효과음
- 글자가 찍히는 동안 짧은 발화 톤이 울린다
- 타자기 소리가 아니라 말하는 소리다
- 3글자마다 한 번 울린다
- 직전 소리로부터 60ms가 지나지 않았으면 건너뛴다
- 재생마다 피치를 ±6% 범위에서 무작위로 흔든다
- 마지막 글자에는 울리지 않는다
- 퇴장 페이드와 스킵에는 소리가 없다
- 에셋 파일이 없으면 무음으로 동작한다

### 선택지 버튼
- 타이핑이 끝난 뒤 0.15초에 걸쳐 나타난다
- 숨어 있는 동안 그 자리를 클릭하면 스킵이 동작한다
- 자리는 항상 차지하고 있어 등장할 때 말풍선이 밀리지 않는다

### 도장
- 타이핑이 끝난 뒤 팝한다
- 사라질 때는 문구와 함께 퇴장 페이드를 탄다
- 소리는 붙지 않는다

### 클릭
- 클릭은 스킵 전용이다
- 퇴장 페이드 중이나 타이핑 중에 배너를 클릭하면 현재 문장이 즉시 완성된다
- 즉시 완성에는 선택지 등장과 도장 팝이 포함된다
- 완성 상태에서 클릭하면 넘길 다음 문장이 있을 때만 넘어간다
- 지금은 한 반응이 항상 한 문장이므로 완성 상태의 클릭은 아무 일도 하지 않는다

### 새 반응이 도착했을 때
- 완성된 문장이 떠 있으면 퇴장 300ms를 온전히 쓴다
- 아직 퇴장 중이거나 타이핑 중이면 퇴장을 80ms로 줄인다
- 퇴장은 다 한 말을 거두는 동작이라, 아직 안 끝난 말은 짧게만 거둔다
- 사용자 유발 반응은 항상 현재 연출을 갈아탄다. 할 일 완료와 습관 체크가 여기 속한다
- 자동 발생 반응은 연출이 재생 중이면 버려진다. 세션 완료가 여기 속한다
- 버려진 세션 반응의 노트는 오늘의 집중 목록에서 달 수 있다

### 적용 범위
- 대화 라우팅의 노드 전환도 같은 연출을 탄다
- 노트 입력 모드는 연출 없이 즉시 표시된다. 모드 전환이라 찍을 문장이 없다
- 대기 갱신이 같은 문구를 다시 적용해도 다시 찍히지 않는다
- 완료 반응과 같은 순간에 일어난 대기 갱신은 반응에 밀린다. 대기 문구가 먼저 번쩍이지 않는다

## 범위 아님
- **여러 문장으로 이어지는 발화** — 이번엔 한 반응이 항상 한 문장이다. 온보딩과 긴 대화 작업에서 다룬다
- **컴패니언 음성 볼륨 UI** — 필드만 이번에 넣는다. 노출은 설정 화면 배선 작업에서
- **알람 전용 볼륨 필드** — 요구가 없다
- **모션 줄이기 옵션** — 요구가 없다
- **보조 줄 타이핑** — 헤이즐의 문장이 아니다
- **크로스페이드 방식** — 라벨을 둘로 늘려야 하고 사라지는 글자와 찍히는 글자가 겹친다
- **아바타 포즈와 표정 변화** — 페르소나 §8의 포즈 목록은 별도 작업
- **배너 밖의 위젯 애니메이션** — 콘텐츠 스왑 전환과 리스트 행 상태 변화는 후속 작업
- **효과음 에셋 제작** — 사용자가 직접 준비한다

## 메커니즘 영향
- `AppSettings`에 컴패니언 음성 볼륨 필드를 추가한다. 0~1 float, 기본값 1.0
- `from_dict`이 키가 없으면 기본값을 유지하므로 마이그레이션과 `version` 증가는 없다
- `save.json`의 `settings`에 키가 하나 늘어난다
- `Sound`에 발화음 전용 `AudioStreamPlayer`와 재생 메서드를 추가한다
- 기존 `_player`와 `play_set()`은 손대지 않는다. 완료음과 발화음이 서로 끊지 않게 하려는 분리다
- 전용 플레이어도 기본 버스를 쓰므로 마스터 볼륨과 음소거가 그대로 걸린다
- 시그널 배선은 바뀌지 않는다
- `CompanionEngine`의 반환 계약은 바뀌지 않는다

## 관련 파일
- `scripts/companion/companion_banner.gd` — 연출 전부
- `scripts/audio/sound.gd` — 전용 플레이어와 발화음 재생
- `scripts/data/app_settings.gd` — 컴패니언 음성 볼륨 필드
- `assets/sounds/` — 발화음 에셋이 놓일 자리
- `scenes/MainShell.tscn` — 편집하지 않는다. 노드 추가 없이 코드에서만 처리한다
