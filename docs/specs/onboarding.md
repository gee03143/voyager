# 온보딩

첫 실행에서 헤이즐이 집사로 부임하고, 유저에게 호칭과 할 일 하나를 받은 뒤 물러나는 대화 시퀀스.

⚠️ **2026-09-21 전면 교체.** 이전 판은 `이웃` 페르소나 + 시메지 말풍선 4문장 기준이었다. 근거는 `docs/adr/0001-companion-butler-rp.md`.

- 헤이즐이 누구인가 — `docs/companion-persona.md`
- 대사 전문 — `docs/companion-butler-draft.md` §1
- 이 문서 — **어떻게 동작하는가**

## 동작

### 자리

- 온보딩은 **셸 창**에서 재생된다
- `MainShell`이 품는 **오버레이 노드**다. 창을 갈아끼우지 않는다
- ⚠️ 시메지 말풍선에서 재생하지 않는다. **시메지에는 발화 채널이 없다**
- 오버레이인 이유는 완료 연출이다. 걷히면 그 뒤에 도구가 이미 드러나 있다
- `MainShell`은 재생하지 않고 품기만 한다. `finished` 시그널 하나만 받는다
- 창 크기는 `Save.settings.window_size` 그대로 쓴다. 본문만 중앙 컬럼으로 묶는다
- ⚠️ 온보딩 동안만 창을 작게 띄우는 방식은 `Screen` autoload를 건드리므로 이번 범위가 아니다

### 트리거

- 첫 실행에서 한 번만 재생된다
- `Save.settings.onboarded`가 거짓일 때 재생한다
- 완료된 뒤에는 어떤 경로로도 다시 재생되지 않는다
- 이미 활동 기록이 있는 저장 파일은 완료된 것으로 간주한다
- 헤이즐은 온보딩의 존재를 대사로 언급하지 않는다

### 흐름

- 비트가 일곱이다. 도착 / 고용되지 않은 집사 / 대신할 수 없는 것 / 이름 / 할 수 있는 일 / 첫 부탁 / 물러남
- 비트마다 선택지가 네 개다. 이름과 첫 부탁 비트는 자유 입력을 받는다
- **모든 선택지가 같은 지점으로 수렴한다.** 분기가 갈리지 않는다
- 선택지가 바꾸는 것은 헤이즐의 반응 한 묶음뿐이다
- 반응은 선택지마다 다르다. 같은 답이 돌아오면 답정너인 것이 들킨다
- 원점으로 되돌아오는 선택지는 두지 않는다
- ⚠️ 유저의 거부는 분기가 아니라 개그 리액션이다. 근거는 페르소나 §5

### 줄

- 줄 종류가 셋이다. **지문 / 대사 / 내레이터**
- 셋은 시각적으로 구분된다. 규격은 페르소나 §8
- 타이핑 속도를 줄 종류별로 다르게 둔다. 같은 속도면 지문이 늘어진다
- 초안값은 지문 14ms/자, 대사 26ms/자다. F6에서 눈으로 조정할 값이다
- 줄이 완성되면 잠깐 머문 뒤 다음 줄로 자동으로 넘어간다
- 머무는 시간 초안값은 대사 420ms, 지문 260ms다

### 진행

- 화면을 클릭하면 타이핑 중인 줄이 즉시 완성된다
- 완성된 줄을 클릭하면 머무는 시간을 건너뛰고 다음 줄로 넘어간다
- 선택지는 그 비트의 마지막 줄이 완성된 뒤에 나타난다
- 건너뛰기 버튼은 두지 않는다. 답정너라 되돌릴 것이 없고 소요가 2~3분이다
- 지나간 줄은 화면에 남는다. 비트가 바뀔 때 비운다

### 입력

**두 개를 받는다. 둘 다 비워둘 수 있다.**

- **호칭** — 이름 비트. 자유 입력
- **내일 할 일** — 첫 부탁 비트. 자유 입력 또는 선택지
- 비워두면 헤이즐이 기본값을 적고 넘어간다. 다시 묻지 않는다
- ⚠️ **어떤 경로로도 데이터가 남는다.** 이것이 온보딩의 완료 판정 기준이다
- ⚠️ 첫날 저널은 받지 않는다. 자기 개방이 필요해 첫 입력으로는 문턱이 가장 높다
- ⚠️ `비워두셔도 됩니다` 류의 출구 문장을 매 단계 붙이지 않는다. 이탈로가 된다

### 저장되는 것

- 호칭은 `AppSettings.nickname`에 들어간다. 비우면 빈 문자열이다
- 할 일은 기본 그룹(`Save.todo_groups[0]`)에 `Todo` 하나로 들어간다
- 그 `Todo`의 `due_date`는 **내일**이다
- 비워두면 `아무것도 안 하기`를 텍스트로 넣는다. 이것도 일이다
- Todo 저장은 기존 디바운스 정책을 탄다

### 배너

- ⚠️ `CompanionBanner._ready()`가 시그널 다섯을 구독하고 즉시 `_refresh()`를 부른다
- 처리하지 않으면 **전면에는 격식체 집사가, 아래 배너에는 구 페르소나 헤이즐이 동시에 뜬다**
- 온보딩 시작 시 배너를 숨긴다
- 완료 시 배너를 되살리고 갱신한다
- 배너 쪽 대사 교체는 이 문서 범위가 아니다

### 시메지

- 온보딩 중에는 시메지가 자기 일을 시작하지 않는다
- 걷기로 창이 움직이면 대본과 어긋난다. 헤이즐은 집 안에 있다
- 생리적 움직임(호흡·깜빡임)은 그대로 돈다
- 만지기·끌기는 막지 않는다

### 완료

- 마지막 비트가 끝나면 오버레이를 제거한다
- 그다음 셸 창을 숨긴다. 대본의 「물러남」이 곧 이 숨기기다
- **끝나는 화면을 두지 않는다.** `완료` 버튼도 축하 문구도 없다
- 온보딩이 끝났다고 선언하는 순간 "헤이즐이 화면에서 안 나간다"는 약속이 깨진다
- 시메지의 자기 일이 여기서 다시 돈다

### 중단

- 완료 전에 앱을 끄면 다음 실행에서 처음부터 다시 재생된다
- 중간 진행 상태를 저장하지 않는다
- 재생 도중에는 다른 반응이 화면을 갈아치우지 않는다

### 대사

- 대사·지문 전문은 `docs/companion-butler-draft.md` §1이 갖는다
- 이 문서는 대사를 옮겨 적지 않는다. 두 곳에 적으면 단일 진실이 깨진다
- 대사 승인은 페르소나 §0의 빠른 판정으로 한다

## 범위 아님

- 대사·지문 전문. `companion-butler-draft.md` 관할
- 페르소나 규격(화법·온기 통로·금지). `companion-persona.md` 관할
- 영어 대사. 한국어가 확정된 뒤 따로 쓴다
- **도구 도움말.** 조작법은 도구를 처음 열 때 도구 안에서 알린다
- 배너 대사 교체. `COMPANION_*` 전량이 구 페르소나라 별도 작업이다
- 시메지 셸 자체. 투명 창·상주·클릭 반응·자기 일 목록
- 우클릭 메뉴 구성
- 온보딩 동안 창 크기를 줄이는 것. `Screen` autoload를 건드린다
- 생일 입력. 페르소나 §3에 따라 헤이즐은 묻지 않는다
- 친밀도, 만난 날 수, 첫 만난 날 저장
- 설정의 `내보내기` 통로
- 아바타 포즈·표정 변화. 대화 화면은 텍스트만 쓴다
- 온보딩 다시 보기 메뉴
- 건너뛰기 버튼
- 온보딩 전용 효과음
- 헤이즐이 다음 날 할 일을 실제로 알리는 동작. 알림은 별도 기능이다

## 메커니즘 영향

### 저장

- `AppSettings`에 `onboarded: bool`을 추가한다. 기본값 거짓
- `AppSettings`에 `nickname: String`을 추가한다. 기본값 빈 문자열
- 저장 위치는 `save.json`의 `settings`다
- 저장 시점은 전역 설정 정책대로 save-on-change다
- ⚠️ 호칭을 `AppSettings`에 두는 이유는 지금 필요한 것이 문자열 하나뿐이기 때문이다. 친밀도가 붙을 때 관계 데이터 모델로 옮긴다 — 두 번째 사례에서 추출한다
- `save.json`의 `VERSION`은 올리지 않는다. 키가 없는 기존 파일은 기본값으로 읽힌다
- 로드 시 `onboarded` 키가 없고 활동 기록이 비어 있지 않으면 참으로 채운다
- 저장 파일 구성은 바뀌지 않는다. `todo.json`에 `Todo` 하나가 더 들어갈 뿐이다

### 진입점

- `shimeji_root.gd`의 셸 구성에서 `onboarded`를 본다
- 거짓이면 `MainShell`에 온보딩 오버레이를 붙이고 셸 창을 띄운다
- 참이면 지금 동작 그대로다. 셸은 숨은 채로 만들어진다
- `shimeji_root.gd`의 자기 일 타이머에 게이트를 하나 넣는다
- ⚠️ `Screen.bind_shell`은 Window만 잡고 자식 내용물을 보지 않으므로 그대로 둔다

### 셸

- `main_shell.gd`가 온보딩 오버레이를 붙이고 `finished`를 받는다
- 완료 시 오버레이를 제거하고 배너를 되살린다
- 셸 숨기기는 `shimeji_root`가 한다. `MainShell`은 창을 모른다

### 배너

- `CompanionBanner`에 숨김·복구 공개 메서드를 하나 둔다
- 복구 시 `_refresh()`를 다시 태운다
- ⚠️ 시그널 구독을 끊지는 않는다. 온보딩 중에는 활동이 없어 실해가 없다

### 대본 데이터

- `res://data/onboarding.json`을 새로 둔다. 구조(비트 → 줄 → 선택지 → 수렴)만 담고 키를 가리킨다
- 문자열은 `localization/translations.csv`의 `ONB_*`에 둔다
- 지문과 내레이터도 번역 대상이다
- ⚠️ 대본을 코드에 박지 않는다. 앞으로 수십 번 고칠 텍스트다
- `CompanionEngine`은 건드리지 않는다. 온보딩은 순수 대본 재생이라 판단이 없다
- `CompanionBanner`의 타이핑 계약을 공유하지 않는다. 줄 종류가 셋이라 규격이 다르다

### 신규 파일

- `scenes/Onboarding.tscn` — 오버레이 씬
- `scripts/onboarding/` — 재생기

기존 `.tscn`은 건드리지 않는다.

## 선행 조건

- 시메지 셸과 셸 창 구조는 이미 있다. `shimeji_root.gd` 기준으로 동작 중이다
- 추가 선행 조건 없다
