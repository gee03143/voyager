# 시메지

헤이즐이 바탕화면에 상주하는 창. 다이어리 셸과 별개로 떠 있고 셸을 닫아도 남는다.

## 동작

### 자리
- 앱을 켜면 시메지가 바탕화면에 뜬다
- 다이어리 셸을 닫아도 시메지는 남는다
- 시메지를 끄는 것이 앱을 끄는 것이다
- 투명 창의 기술 계약은 `docs/architecture/transparent-window.md`가 갖는다

### 창
- 테두리가 없고 배경이 투명하다
- 항상 다른 창 위에 있다
- 크기는 캐릭터가 들어갈 만큼이다. 초안값 280x340
- 투명한 픽셀은 클릭이 통과하고 그려진 픽셀만 클릭을 받는다
- 말풍선이 떠 있는 동안은 말풍선도 클릭을 받는다

### 이동
- 캐릭터를 끌어서 옮긴다
- 놓은 자리를 저장하고 다음 실행에 그 자리에 뜬다
- 저장된 자리가 지금 화면 밖이면 기본 자리로 돌아온다
- 기본 자리는 주 모니터 우하단이다

### 좌클릭 — 승인 필요
- 누르는 자리로 갈린다. 이마와 그 밖이다
- 이마를 누르면 쓰다듬기가 시작되고 누르고 있는 동안 이어진다
- 쓰다듬는 중에 커서가 이마를 벗어나면 들어올리기로 바뀐다
- 이마 밖을 누르고 끌면 들어올려진다. 목덜미가 커서에 붙고 몸이 진자로 흔들린다
- 이마 밖을 누르고 끌지 않으면 아무 일도 일어나지 않는다
- 높은 자리에서 놓으면 떨어져 착지한다
- 이마 판정은 뷰가 갖는다. 파츠가 바뀌면 판정 영역도 같이 움직여야 한다

### 우클릭
- 메뉴가 뜬다
- 도구를 고르면 다이어리 셸이 그 도구로 열린다
- 셸이 이미 열려 있으면 앞으로 가져오고 그 도구로 바꾼다
- 메뉴 맨 아래에 종료가 있다
- 항목은 홈 / 할일 / 습관 / 타이머 / 일지 / 기록 / 종료다
- 설정은 넣지 않는다. 사이드바에 설정 진입점이 없어 갈 곳이 없다
- 메뉴 문구는 중립 UI 언어다. 헤이즐이 말하는 자리가 아니다 (페르소나 §5)

### 혼잣말
- 말풍선이 떴다가 스스로 사라진다
- 답을 요구하지 않는다. 선택지가 붙지 않는다
- 기능은 자기진술과 관찰뿐이다 (페르소나 §5)
- 풀은 친밀도 단계를 타지 않고 친밀도가 쌓이면 덧붙는다 (페르소나 §6)
- 간격 초안값은 4~9분 무작위
- 머무는 시간 초안값은 2초 + 글자당 60ms
- 말풍선을 클릭하면 즉시 사라진다
- 타이핑 연출은 배너와 같은 규격을 쓴다 (`companion-banner-typing.md`)

### 행동
- 평소에는 생리적 움직임만 돈다. 숨·깜빡임·귀 움찔·꼬리 흔들림
- 자기 일은 드물게 나온다. 초안값 하루 3~5회
- 이번에 넣는 자기 일은 책읽기·걷기·도토리 묻기 셋이다
- 걷기는 화면 가장자리를 넘지 않는다
- 도토리를 묻으면 그 자리에 흙더미가 잠깐 남는다
- 행동이 도는 동안에도 혼잣말은 평소대로 나온다

### 타이머
- 뽀모도로나 타이머가 돌면 캐릭터 아래에 남은 시간이 뜬다
- 세션이 없으면 아무것도 뜨지 않는다

### 세션 중
- 혼잣말이 멈춘다. 말풍선이 작업 창을 가리기 때문이다
- 드물게 나오던 자기 일이 멈춘다
- 대신 세션용 자기 일 하나가 계속 돈다 (페르소나 §3의 co-presence)
- 세션이 끝나면 평소로 돌아온다

### 혼잣말 초안 — 승인 필요

| 키 | ko | en |
|---|---|---|
| `COMPANION_MUTTER_ACORN` | 도토리 어디 뒀더라. | Where'd I put that acorn. |
| `COMPANION_MUTTER_WIND` | 오늘은 바람이 차네. | Wind's got a bite today. |
| `COMPANION_MUTTER_PILE` | 이거 쌓이는 거 좋아해. | I like watching these pile up. |
| `COMPANION_MUTTER_WINTER` | 겨울 오기 전에 다 묻어야 해. | Got to bury it all before winter. |
| `COMPANION_MUTTER_SHORT` | 낮이 짧아졌어. | Days are getting short. |
| `COMPANION_MUTTER_LEAVES` | 낙엽 색이 바뀌었네. | Leaves turned. |

규격 검증(§5·§0 기준): 한국어 최장 16자, 느낌표 0, 2인칭 0, 3인칭 자칭 0, 쉼표 0. 전부 자기진술 아니면 관찰이다. 로어는 설명 없이 흘린다.

## 범위 아님
- 매달리기. 팔 길이가 모자라 메시 변형 리그로 옮긴 뒤에 한다
- 다른 앱 창 위에 올라타기. 타 창의 좌표를 읽는 수단이 없다
- 트레이 아이콘
- 시메지 여러 마리
- 시메지에서의 대화 라우팅·선택지·기록 열람. 전부 셸 안이다
- 계절과 시간에 따른 무대 변화
- 시메지 크기 설정
- 최종 아트. 임시 도형 파츠로 간다
- 온보딩. `onboarding.md` 관할이고 이 spec 뒤에 온다

## 메커니즘 영향
- 메인 씬이 `MainShell.tscn`에서 `Shimeji.tscn`으로 바뀐다
- 루트 창이 시메지다. 투명·테두리 없음·항상 위를 프로젝트 설정으로 준다
- 다이어리 셸은 자식 `Window`이고 그 안에 `MainShell`이 들어간다
- 셸을 닫으면 숨긴다. 앱은 끝나지 않는다
- 앱을 끝내는 유일한 길은 시메지의 우클릭 메뉴다
- 셸이 자식 창이어야 하는 이유는 창 목록이다. 주 창은 숨겨도 작업표시줄에서 빠지지 않는다
- `Screen`이 주 창 대신 셸 창을 가리킨다. 루트가 `bind_shell`로 넘긴다
- 비포커스 FPS에 하한을 둔다. 시메지가 늘 보이므로 10으로 내리면 움직임이 끊긴다
- `Screen.enter_companion`과 `exit_companion`이 폐기된다
- `MainShell`의 미니 모드 버튼이 셸 숨기기로 바뀐다
- `get_tree().root.gui_embed_subwindows = false`가 필요하다
- `default_clear_color`는 이미 알파 0이라 추가 작업이 없다
- `AppSettings`에 시메지 창 위치를 둔다. 저장은 save-on-change다
- 기존 `companion_position`을 재사용할지 새 키를 둘지는 구현 시 정한다
- `Screen.enter_companion`과 `exit_companion`이 쓰이지 않게 된다
- `MainShell`의 미니 모드와 `MINI_WIDGET_GROUP` 배선이 쓰이지 않게 된다
- 말풍선 뷰가 새로 필요하다. 배너의 타이핑 연출 규격을 공유한다
- `CompanionEngine`에 혼잣말 풀과 선택 규칙을 더한다
- 신규 번역 키 `COMPANION_MUTTER_*`와 우클릭 메뉴 라벨을 더한다
- 시그널이 둘 는다. 시메지가 셸 열기를 요청하는 것과 셸이 닫혔음을 알리는 것
- 저장 파일 구성은 바뀌지 않는다
